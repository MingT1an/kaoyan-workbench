## 1. 项目背景与定位

备考研究生入学考试是一条以「天」为单位的长跑，日常会同时管理五条线：**计划、专注、错题、复习、复盘**。这些信息通常分散在纸笔、手机 App 和表格里——数据不互通、回顾成本高、难以坚持。

**定位**：一款单机、离线、本地数据的桌面工作台，把备考闭环装进一个窗口：

> 今天学什么（计划） → 专注多久（番茄钟） → 哪里薄弱（错题本） → 何时巩固（艾宾浩斯复习） → 效果如何（统计）。

**目标用户**：备考研究生入学考试的考生（默认按 2027 届预置考试日期 2026-12-26，可随时修改，以教育部公告为准）。

**一句话价值**：打开电脑就能进入备考状态——倒计时、今日任务、待复习卡片、专注时长，一屏可见。

## 2. 设计原则

1. **本地优先**：所有数据存本机（`%APPDATA%/KaoyanWorkbench`），无账号、无网络请求、无遥测。
2. **低摩擦**：高频动作——勾掉任务、开始专注、复习一张卡——不超过 2 次点击。
3. **可坚持**：用倒计时、连续打卡、复习角标提供正反馈，而不是制造焦虑。
4. **数据可带走**：一键导出/导入完整备份（含错题截图），数据永远属于用户。

## 3. 核心使用场景（用户旅程）

| 时段 | 场景 | 用到的模块 |
| --- | --- | --- |
| 早晨 · 3 分钟 | 打开今日页，看倒计时与当前阶段，把今天的任务列上 | 今日、计划 |
| 白天 · 循环 | 选科目/任务 → 专注 25 分钟 → 自动休息 5 分钟，每 4 个番茄长休 15 分钟 | 专注 |
| 随时 · 2 分钟 | 遇到错题，截图或粘贴录入错题本，勾选「加入复习队列」自动进入艾宾浩斯调度 | 错题本、复习 |
| 晚间 · 10 分钟 | 清空今日到期复习卡 → 看今日时长与连续打卡 → 规划明天 | 复习、统计 |

## 5. 页面与交互说明

**今日（Today）**
- 顶部问候 + 日期 + 当前所处备考阶段（基础/强化/冲刺，按设置中的日期区间判定）。
- 三张核心卡：距考试天数（大号数字）、今日专注（分钟 + 番茄数 + 每日目标环）、待复习（到期卡片数，一键跳转复习页）。
- 今日任务卡：勾选完成、行内快速添加；下方为最近专注记录。

**计划（Plan）**
- 日期切换（‹ 今日 › + 日期选择器），展示当日任务：未完成在前，已完成置灰在后。
- 快速添加行：标题（回车即添加）+ 科目 + 预计分钟 + 重复规则（不重复/每天/工作日）。
- 「逾期未完成」区：汇总今天之前未勾选的任务，可一键改期到今天。
- 点击任务弹出编辑弹窗（改标题/科目/日期/时长/重复），可删除。

**专注（Focus）**
- 大号倒计时 + 状态（专注中 / 已暂停 / 休息中 / 长休息 / 待开始）。
- 开始前选择科目与关联任务（可选，默认今日未完成任务）；运行中锁定选择。
- 控制：开始 / 暂停 / 继续 / 结束（休息中为「跳过休息」）。专注自然结束自动进入休息并弹通知；每满 N 个番茄进入长休息。
- 下方为今日专注记录（时间段、时长、科目、是否完整完成）。

**错题本（Mistakes）**
- 顶部搜索 + 科目筛选；卡片列表展示题目摘要、科目、章节、掌握度与「复习中」标记、缩略图。
- 新建/编辑弹窗：科目、章节、题目（必填）、我的错因、正确解法、掌握度、截图（弹窗内可直接 Ctrl+V 粘贴，或选择本地文件），勾选「加入复习队列」（默认勾选）→ 以题目为正面、解法为背面生成复习卡。
- 删除错题会同时移除其生成的复习卡（有确认）。

**复习（Review）**
- 概览：今日到期 N 张、已复习 X 张、卡片总数。
- 逐张复习：正面（题目）→ 点击显示答案 → 三档反馈「忘了 / 模糊 / 记得」，反馈后自动调度并进入下一张；支持删除卡片。
- 全部清空后展示祝贺态与「即将到来」列表（未来到期，按日期分组显示最近若干张）。
- 支持手动新建卡片（不依赖错题本）。

**统计（Stats）**
- 指标卡：今日专注、近 7 天、连续打卡、累计专注（含完成番茄数）。
- 近 14 天专注趋势柱状图；科目分布支持 近7天 / 近30天 / 全部 切换；今日任务完成进度条。

**设置（Settings）**
- 考试与阶段：考试日期、阶段规划（名称 + 起止日期，可增删改）。
- 科目管理：名称 + 颜色，可增删（删除后历史记录归入「未分类」）。
- 番茄钟：专注/短休/长休分钟数、每 N 个番茄长休、每日目标番茄数。
- 复习：艾宾浩斯间隔序列（默认 `1,2,4,7,15,30`）。
- 通用：关闭最小化到托盘、专注结束后自动休息。
- 数据：显示数据文件路径、打开数据目录、导出备份、导入备份（导入前确认覆盖）。

## 6. 关键规则与口径

| 规则 | 定义 |
| --- | --- |
| 有效会话 | 实际专注 ≥ 1 分钟才入库；提前结束按实际秒数计入统计 |
| 打卡日 | 当日有效专注 ≥ 25 分钟；连续打卡从今天（若今天尚未达标则从昨天）向前连续计数 |
| 番茄完成 | `mode=focus` 且自然结束的会话数；当日第 4、8… 个完成后进入长休息 |
| 艾宾浩斯 | 默认间隔 1/2/4/7/15/30 天（可配）；**记得** → 进入下一档；**模糊** → 档位不变、明天再见；**忘了** → 回到第 0 档（明天再见）；反馈结果同步回写错题掌握度（忘了→未掌握，模糊→模糊，记得→已掌握） |
| 重复任务 | 设了重复规则的行是「模板」；对晚于模板日期的每一天按规则自动生成当日实例，实例可独立完成/删除；模板不进入逾期统计 |
| 阶段判定 | 今天 ∈ [start, end] 的阶段即当前阶段；默认 基础(03-01~07-31)、强化(08-01~10-31)、冲刺(11-01~12-25) |
| 倒计时 | 考试日 − 今天（自然日）；默认考试日 2026-12-26（2027 考研初试预计，以教育部公告为准） |

## 7. 数据模型

```ts
Subject      { id, name, color, order }
Phase        { id, name, start, end }                    // 阶段规划
Task         { id, title, subjectId|null, date, estimatedMinutes|null,
               repeatRule: 'daily'|'weekdays'|null,      // 非 null 即模板
               repeatOf: templateId|null,                // 生成的实例指向模板
               status: 'todo'|'done', note, createdAt }
FocusSession { id, date, subjectId|null, taskId|null, taskTitle|null,
               startedAt, endedAt, plannedMinutes, actualSeconds,
               status: 'completed'|'stopped', mode: 'focus' }
Mistake      { id, subjectId|null, chapter|null, question, wrongReason|null,
               solution|null, images: string[],          // media:// 引用的文件名
               mastery: 'unknown'|'fuzzy'|'mastered',
               inReview: boolean, createdAt }
ReviewCard   { id, sourceType: 'mistake'|'manual', sourceId|null, subjectId|null,
               title, content|null, intervalIndex, nextDue, lastResult|null,
               lastReviewedAt|null, createdAt }
Settings     { examDate, phases: Phase[], focusMinutes, breakMinutes,
               longBreakMinutes, longBreakEvery, dailyGoalPomodoros,
               reviewIntervals: number[], closeToTray, autoStartBreak }
```

存储实现：单文件 `data.json`（内存操作 + 防抖 400ms 落盘，写临时文件后原子替换，崩溃安全）；截图存 `images/` 目录，渲染进程通过自定义 `media://` 协议只读加载（校验文件名，防路径穿越）。

## 8. 技术选型

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 桌面壳 | Electron 44 + electron-vite 5 | 主/预加载/渲染三端一体构建；沿用本机已验证的版本组合 |
| 渲染层 | React 19 + TypeScript 7 | 组件化 + 类型安全；TS7（native）编译快 |
| 样式 | Tailwind CSS 4 + 自定义主题变量 | 深色专注主题，无额外运行时 |
| 图标 | lucide-react | 统一线性图标风格 |
| 存储 | 本地 JSON（自有存储层） | 单机数据量小（年千级会话），零原生依赖、随装随用、备份即拷贝；未来量级上来可平迁 SQLite |
| 进程模型 | 主进程持有番茄状态机与数据层 | 关窗进托盘后计时/通知照常工作；渲染层通过 IPC 读写 |

## 9. 视觉与设计规范（V1.1 更新：液态玻璃浅色主题）

- **设计语言**：参考 iOS 26「Liquid Glass」——彩色渐变壁纸打底，磨砂玻璃面板悬浮其上；白色高光描边 + 顶部内发光营造玻璃质感；大圆角（20–26px）、轻投影，内容层级用透明度与模糊表达。
- **壁纸**：固定多层径向渐变（蓝/紫/薄荷/琥珀），由 `body::before` 承载；玻璃面板通过 `backdrop-filter: blur + saturate` 采样其上。
- **三档材质**：卡片 `glass`（白 58% + blur 28px）、侧栏 `glass-rail`（白 46% + blur 24px）、弹窗 `glass-strong`（白 80% + blur 36px）。
- **色彩（iOS 系统色）**：主色蓝 `#007AFF`、绿 `#34C759`、橙 `#FF9500`、红 `#FF3B30`；正文 `#1B2230`、弱文本 `#68738A`；科目默认色 政治=橙、英语=绿、数学=蓝、专业课=紫，可在设置中自定义。
- **字体**：系统 UI 栈（Segoe UI Variable/苹方/微软雅黑）；数字一律 `tabular-nums`；页标题 24px 加粗、倒计时 72px。
- **控件**：输入框/按钮 13px 圆角（主按钮带蓝色渐变与内高光）、筛选用胶囊 chip、iOS 绿色拨动开关、圆形玻璃复选框、玻璃弹窗（背景压暗 + 轻模糊）。
- 深色玻璃主题列为后续版本待办。

## 10. 非功能需求

- **数据安全**：写入采用「临时文件 + 原子替换」；导出备份含全部数据与截图。
- **性能**：冷启动 < 3s；数据常驻内存，页面切换与查询均为内存级。
- **隐私**：完全离线，无网络请求、无遥测。
- **健壮性**：单实例锁；渲染层崩溃不影响主进程计时；备份导入前做结构校验。

## 12. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 工具用两天就弃 | 打卡/连续天数/复习角标构成每日正反馈闭环；高频操作两步以内 |
| 数据丢失 | data.json 原子写 + 一键导出备份；数据目录可在设置中直达 |
| 原生依赖安装失败 | V1.0 存储层零原生模块，任何机器 `npm install` 即可运行 |
| 考试日期未公布 | 考试日期是设置项，公告后一键更新；倒计时自动重算 |
| 系统休眠导致计时偏移 | 已知限制：休眠期间按墙钟补记；后续版本改用活跃时长累计 |

## 13. 验收标准（本期 DoD）

1. `npm install && npm run dev` 可启动，七大页面全部可用；
2. 闭环 A：建任务 → 关联专注 → 完成番茄 → 统计与今日页数字正确增长；
3. 闭环 B：录错题（含截图）→ 自动生成复习卡 → 复习反馈 → 掌握度回写、到期日按规则推进；
4. 重复任务在次日自动出现当日实例；逾期任务可在计划页集中处理；
5. 托盘常驻：关窗后计时继续、完成弹通知、托盘可快捷开始/停止；
6. 导出备份 → 清空 → 导入后数据一致（含截图可显示）；
7. `npm run typecheck`、`npm run build`、`npm run smoke` 全部通过。
